Hungary NO₂ & Land Cover Analysis

Environmental Monitoring using Remote Sensing & GIS

Project Overview

This project analyzes nitrogen dioxide (NO₂) concentration levels and Land Cover Change (LCC) patterns across Hungary using geospatial data from 2021–2023. The analysis combines atmospheric monitoring data with land use classification to understand environmental changes.

Technologies Used

🗺️ Mapbox GL JS

Interactive web mapping for tile-based visualization

🐍 Python + GDAL

Geospatial data processing and tile generation

📊 Chart.js

Data visualization for statistical analysis

🌍 OpenStreetMap

Open-source base map layers

Data Sources

Dataset Source Period Resolution
NO₂ Concentration CAMS (Copernicus Atmosphere Monitoring Service) 2021–2023 0.1° × 0.1°
Land Cover Change CORINE Land Cover 2021–2023 100m
Administrative Boundaries EuroGeographics 2023 Vector

Study Area

Location: Hungary, Central Europe

Area: 93,030 km²

Coordinates: 45.7°N – 48.6°N, 16.1°E – 22.9°E

The analysis focuses on urban and agricultural regions to assess the relationship between land use patterns and air quality indicators.
